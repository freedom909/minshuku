## 🎯 项目目标
MACHINE 是一个 **智能化服务平台**，为业务提供三大核心能力：  
1. **客户服务 AI** —— 提升用户体验，自动化交互  
2. **数据分析 AI** —— 支持业务洞察，辅助决策  
3. **推荐系统 AI** —— 个性化推荐，提高转化率  

---

## 🏗 架构领域

### 💬 领域 1：客户服务
- 📝 标题优化（`suggestTitleImprovements`）  
- 📄 描述生成（`generateDescriptionSuggestions`）  
- 💬 评论回复（`generateReplyToReview`）  
- 🚀 绩效改进建议（`getPerformanceTips`）  

### 📊 领域 2：数据分析
- 👣 用户行为追踪  
- 🔬 A/B 测试结果分析  
- 📈 销售预测  
- ⚠️ 异常检测  

### ✨ 领域 3：推荐系统
- 👥 协同过滤推荐  
- 📚 内容匹配推荐  
- 🎯 个性化排序  
- ⚡ 实时推荐（基于用户上下文）
